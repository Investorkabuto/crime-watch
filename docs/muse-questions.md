# Muse への確認事項

Crime Watch（犯罪データの収集・公開アプリ）に、Muse から犯罪・判決データを送ってもらうための確認事項です。
回答をもとに受信データ仕様（`docs/requirements.md` §5）を確定します。

## M1. 事件のひも付け
- 同じ事件の報道（逮捕 → 送検 → 起訴 → 判決）に、**共通の事件 ID（`case_ref`）**を付けられますか。
- 付けられない場合、ひも付けに使える情報（事件の発生日、場所、罪状、被害の内容など）を送れますか。
- 共犯事件で被告人が複数いる場合、判決を被告人ごとに分けて送れますか。

## M2. 判決データの情報源
- 判決の情報はどこから取る想定ですか（ニュースの判決報道、裁判所の判例検索、その他）。
- 次の項目はどのくらいの割合で取れそうですか。

| 項目 | 取れる／一部取れる／取れない |
|---|---|
| 裁判所名 | |
| 審級（一審・控訴審・上告審） | |
| 判決日 | |
| **裁判官の氏名**（裁判長・陪席・単独の区別も） | |
| 裁判員裁判かどうか | |
| 刑の種類・刑期・執行猶予・罰金 | |
| **求刑** | |
| 控訴したかどうか・確定したかどうか | |

## M3. 被告人の属性と、量刑に影響する事情
**氏名は送らないでください。** 次の項目はどのくらい取れそうですか。

| 項目 | 取れる／一部取れる／取れない |
|---|---|
| 性別 | |
| 年齢（または年代） | |
| 少年かどうか（少年／特定少年（18・19歳）／成人） | |
| 前科の有無（同種前科かどうか） | |
| 罪を認めているか（認否） | |
| 示談が成立したか | |
| 被害額 | |
| 被害者数 | |
| 被害の結果（死亡・重傷など） | |
| 刑の加重・減軽（併合罪加重、酌量減軽など） | |

## M4. 送信の条件
- 送る頻度はどのくらいですか（随時／1時間ごと／1日1回など）。
- 1日あたりの件数の見込みはどのくらいですか（報道・判決それぞれ）。
- HTTPS の POST リクエストで JSON を送れますか。`Authorization` ヘッダーを付けられますか。HMAC 署名は作れますか。
- 失敗したときに再送できますか。
- 罪状は報道の表現のまま（例: 「住居侵入・窃盗」「酒気帯び運転」）送る形で問題ありませんか。

## M5. 内容のルール（お願い）
- 被告人・被疑者・被害者・証人などの**氏名、顔写真、住所、学校名・勤務先は送らない**でください。
- 少年事件は、本人を推知できる情報を特に含めないでください。少年事件かどうかを `is_juvenile` で示してください。
- 見出し・要約は記事の転載ではなく、Muse 自身の文章にしてください。
- 必ず出典 URL を付けてください。
